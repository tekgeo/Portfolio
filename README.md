# Juanita Sánchez — Portfolio

Personal portfolio website showcasing geoinformatics projects, skills, and academic background.

**MSc Geoinformatics Engineering** · Politecnico di Milano · GEO-ENV Track

## Structure

```
├── index.html              ← Main portfolio page
├── assets/
│   ├── css/
│   │   ├── main.css        ← Base template styles (OnePage / BootstrapMade)
│   │   └── custom.css      ← Portfolio theme overrides (warm cream palette)
│   ├── js/
│   │   └── main.js         ← Navigation, scroll, AOS initialization
│   └── img/
│       ├── favicon.png      ← Replace with your favicon
│       └── apple-touch-icon.png
└── README.md
```

## Hosting on GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the branch (`main`) and folder (`/ (root)`).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
